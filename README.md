# منصة الإدارة المدرسية المتكاملة

نظام إداري متكامل لمجمع الخشعة التعليمي للبنين — عربي بالكامل وباتجاه RTL، يعمل محلياً دون إنترنت عام ودون ذكاء اصطناعي (كلاهما اختياري).

## الوحدات
1. **الخطة التشغيلية** — 26 برنامجاً، معالم موزونة، حزم شواهد، طلبات تغيير، اعتماد وإقفال.
2. **اللجان والمجالس** — 6 قوالب رسمية، اجتماعات ومحاضر موقعة، قرارات تنشئ إجراءات إلزامية، مجتمعات تعلم.
3. **الأداء الوظيفي** — دورتا المعلم (تقويم دراسي) والموظف (سنة ميلادية)، جلسات وزيارات، حساب موزون لا يتجاوز يدوياً، تقارير موقعة.
4. **التوأم الرقمي للمبنى** — محرر مخطط تفاعلي بربط ثنائي الاتجاه، عهدة وQR، فحص وجاهزية وصيانة، فحص دون اتصال (PWA).

فوق خدمات مشتركة: شواهد موحدة، مهام، تقويم مزدوج (هجري أم القرى/ميلادي)، وثائق مرقمة برموز تحقق، استيراد آمن بمعاينة وتراجع، تدقيق شامل، نسخ احتياطي مشفر.

## البدء السريع
انظر `docs/INSTALL_MAC_AR.md` (بيئة الاختبار) و`docs/DEPLOY_UBUNTU_AR.md` (الإنتاج عبر Tailscale).

```bash
cp .env.example .env   # وعبئ SESSION_SECRET و BACKUP_PASSPHRASE
docker compose up -d db
npm ci && npx playwright install chromium
npm run db:migrate && npx tsx src/db/seed.ts && npm run db:seed:geometry
npm run dev            # http://localhost:3080
```

لا بيانات موظفين ولا تواقيع ولا أسرار في Git؛ الملفات المرجعية الأصلية في `reference_files/` (متجاهلة)؛ القيم الرسمية تحفظ حرفياً؛ كل سجل مهم مسودة ثم «اعتماد وإقفال»؛ وإعادة الفتح بسبب موثق مع حفظ النسخ.
