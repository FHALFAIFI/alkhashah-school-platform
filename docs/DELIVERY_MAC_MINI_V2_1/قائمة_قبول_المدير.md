# قائمة قبول المدير — الإصدار v2.1 (Mac mini)

> املأ هذه القائمة من متصفحك بعد تسجيل الدخول على `http://192.168.0.48:3080`.
> القبول لا يُعتمد إلا بتوقيعك في نهاية القائمة. لم يُنشأ وسم الإصدار النهائي بعد، وسيُنشأ فقط بعد قبولك.

## أولاً: البرامج

- [ ] لا تظهر أنشطة أو معالم للبرنامج التشغيلي.
- [ ] لا تظهر أوزان أنشطة.
- [ ] لا يظهر قسم «جاهزية الإغلاق».
- [ ] يمكن تحديث نسبة تقدّم البرنامج وحالته مباشرةً.

## ثانياً: الشواهد

- [ ] عند عدم وجود شواهد تظهر: **«لم يتم رفع أي شاهد حتى الآن»**.
- [ ] عند وجود شاهد واحد تظهر: **«تم رفع شاهد واحد»**.
- [ ] عند وجود أكثر من شاهد يظهر **العدد الفعلي** وتاريخ آخر رفع.
- [ ] الشواهد الموجودة تفتح/تُنزّل بشكل صحيح.
- [ ] لا يوجد «مطلوب» أو «متبقٍّ» أو نسبة جاهزية أو قيد إكمال.

## ثالثاً: الميزانية

- [ ] الإيرادات تستخدم مسمّى **«البند»**.
- [ ] المصروفات تستخدم مسمّى **«البند»**.
- [ ] يمكن رفع/ربط إيصال للإيراد والمصروف.
- [ ] الإيصال اختياري.
- [ ] المستندات المرتبطة الموجودة تفتح بشكل صحيح.

## رابعاً: اللجان والمجالس

- [ ] تتوفر قوالب مهام جاهزة قابلة للتعديل.
- [ ] مهام اللجان منفصلة عن أنشطة البرنامج المُزالة.
- [ ] يمكن إسناد المهام للأعضاء مع الصفة/الدور.
- [ ] جدول التوزيع للطباعة يحوي: المهمة، العضو المكلف، الصفة/الدور، توقيع العضو، ملاحظات.
- [ ] التوقيع ليس إلزامياً بشكل عام — فقط لنوع المستند المُهيّأ لذلك.

## خامساً: مؤشرات الأداء

- [ ] «جلسة التخطيط» تظهر.
- [ ] «جلسة التخطيط» لا تُحتسب في التقييم.
- [ ] الدورة التي فيها تخطيط فقط تعرض **«لم يبدأ التقييم بعد»**.
- [ ] نتائج التقييمات السابقة لم تتغيّر ولم تصبح صفراً.

## سادساً: التقارير

- [ ] التقارير ولوحات المتابعة وتصدير Word/Excel لا تُظهر: أنشطة/معالم، أوزان، جاهزية إغلاق، كميات شواهد مطلوبة/متبقية.
- [ ] تبقى: نسبة التقدّم والحالة، معلومات الشواهد الفعلية، الميزانية، النتائج والأثر، الملاحظات والسجل.

## سابعاً: الاستقرار (اختبار المتصفح الحقيقي — بوابة D-029)

- [ ] فتح/إغلاق النوافذ الحوارية يعمل دون خطأ.
- [ ] إلغاء النماذج والتنقّل يعمل بسلاسة.
- [ ] عناصر رفع الملفات تظهر بشكل سليم.
- [ ] لا تظهر رسالة خطأ إنجليزية مثل `insertBefore` أو «Application error».
- [ ] جرّب على الجوال (مقاس ~390×844) وعلى سطح المكتب — لا يوجد تمدّد أفقي.
- [ ] (إن أمكن) جرّب مع تفعيل ترجمة المتصفح — لا ينهار النظام.

> ملاحظة: تصنيف مشكلة `insertBefore` حالياً **«محتمل الإصلاح»**؛ اختبارك الحقيقي أعلاه هو بوابة الاعتماد النهائية.
